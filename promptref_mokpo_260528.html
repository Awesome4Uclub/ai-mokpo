✍ 스크립트 담당 ROLE 01
ChatGPT Gemini Claude
팀 스크립트 프롬프트
"우리 팀 주제: [주제] / 대상: 목포공업고 학생 / 45초 숏폼 스크립트 / 장면 6개
형식: 장면번호 | 자막(대사) | 화면설명 | 이미지 프롬프트(영문)
마지막 장면 임팩트 한 줄 결론"
완료 후: 생성된 스크립트 단톡방에 공유 → 나래이터·이미지 담당이 바로 활용
🎤 나래이터 담당 ROLE 02
Option A — Typecast AI (추천)
🔗 typecast.ai
  1. typecast.ai 접속 → 구글 계정 로그인
  2. 스크립트 대사 붙여넣기 → AI 목소리 선택
  3. MP3 다운로드 → 단톡방에 전송
Option B — 셀프 녹음
  1. 기본 녹음 앱으로 대사 직접 녹음
  2. CapCut → "음질 개선" AI 기능 적용
  3. 파일 → 편집 담당에게 단톡방 전송
🎵 배경음악 담당 ROLE 03
Suno AI
🔗 suno.com
  1. suno.com 접속 → 구글 계정 로그인
  2. "Custom" 선택 → 아래 프롬프트 입력
  3. "Instrumental" 체크 (가사 없음) → 생성 클릭
  4. 30~60초 클립 선택 → MP3 다운로드 → 단톡방 전송
💬 Suno 프롬프트 예시 "upbeat tech background music, motivational, no vocals, Korean youth education short video, 45 seconds, electronic, bright"
팁: 여러 개 생성해서 영상 분위기에 가장 잘 맞는 것 선택
🖼 이미지·영상 담당 ROLE 04
이미지 생성 — Gemini / ChatGPT 앱
  1. Gemini 앱 또는 ChatGPT 앱 열기
  2. 스크립트의 '이미지 프롬프트(영문)' 그대로 입력
  3. 이미지 생성 → 갤러리 저장 → 단톡방 전송
💬 이미지 프롬프트 추가 팁 스크립트 프롬프트 끝에 추가: ", photorealistic, bright lighting, high quality, 16:9"
영상 생성 (선택) — Grok / Flow
🔗 grok.com    🔗 flow.google.com
  1. 접속 → 장면 설명 텍스트 입력
  2. 짧은 클립(3~5초) 생성 → 단톡방 전송
주의: 이미지가 이상하면 프롬프트 더 구체적으로 수정 후 재시도
✂ 편집 담당 ROLE 05
CapCut
  1. 단톡방 소스 파일 전부 다운로드 (이미지·음성·음악)
  2. CapCut 새 프로젝트 → 이미지·영상 클립 순서대로 배치
  3. 나래이터 오디오 삽입 → 클립 길이 맞추기
  4. 배경음악 추가 → 볼륨 20~30%로 낮추기
  5. "텍스트 → 자동 자막" AI 기능 → 폰트·크기·색 조정
  6. 전환 효과 · 필터 적용 (2~3개면 충분)
  7. 1080p 내보내기 → 단톡방 완성본 공유
배터리 50%+ 유지 필수  ·  파일 전송 시 "원본 화질" 선택
Wi-Fi 끊기면 핫스팟 ON  ·  느리면 이미지 5장 이내로 줄이기
