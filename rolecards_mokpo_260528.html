ROLE 01 스크립트 담당
사용 도구
ChatGPT Gemini Claude
작업 순서
  1. ChatGPT 앱 (또는 Gemini·Claude) 열기
  2. 아래 프롬프트 입력 → 장면별 대사·화면설명 생성
  3. 생성된 스크립트 → 단톡방에 텍스트로 공유
    (나래이터·이미지 담당이 바로 활용)
💬 팀 스크립트 프롬프트 "우리 팀 주제: [주제] / 대상: 목포공업고 학생 / 45초 숏폼 스크립트 / 장면 6개 / 형식: 장면번호|자막(대사)|화면설명|이미지 프롬프트(영문) / 마지막 장면 임팩트 한 줄 결론"
ROLE 02 나래이터 담당
사용 도구
Typecast AI 셀프 녹음
🔗 typecast.ai
Option A — Typecast AI (추천)
  1. typecast.ai 접속 → 구글 계정 로그인
  2. 스크립트 대사 붙여넣기 → AI 목소리 선택
  3. MP3 다운로드 → 단톡방 전송
Option B — 셀프 녹음
  1. 기본 녹음 앱으로 대사 직접 녹음
  2. CapCut 내 "음질 개선" AI 기능 적용
  3. 파일 → 편집 담당에게 단톡방 전송
ROLE 03 배경음악 담당
사용 도구
Suno AI
🔗 suno.com
작업 순서
  1. suno.com 접속 → 구글 계정 로그인
  2. "Custom" 선택 → 아래 프롬프트 입력
  3. "Instrumental" 체크 (가사 없음) → 생성
  4. 30~60초 클립 선택 → MP3 다운로드 → 단톡방 전송
💬 Suno 프롬프트 예시 "upbeat tech background music, motivational, no vocals, Korean youth education short video, 45 seconds, electronic, bright"
ROLE 04 이미지·영상 담당
사용 도구
Gemini ChatGPT Grok Flow
이미지 생성 (스마트폰 앱)
  1. Gemini 앱 또는 ChatGPT 앱 열기
  2. 스크립트의 '이미지 프롬프트(영문)' 입력
  3. 이미지 생성 → 갤러리 저장 → 단톡방 전송
영상 생성 (선택)
  1. grok.com 또는 flow.google.com 접속
  2. 장면 설명 입력 → 짧은 클립 생성 → 단톡방 전송
💬 이미지 프롬프트 추가 팁 스크립트 영문 프롬프트 뒤에 추가: ", photorealistic, bright lighting, high quality"
ROLE 05 편집 담당
사용 도구
CapCut
작업 순서
  1. 단톡방 소스파일 전부 다운로드 (이미지·음성·음악)
  2. CapCut 새 프로젝트 → 이미지·영상 클립 순서대로 배치
  3. 나래이터 오디오 삽입 → 배경음악 추가 (볼륨 20~30%)
  4. "텍스트 → 자동 자막" AI 기능 → 자막 크기·색 조정
  5. 전환 효과 · 필터 적용 → 1080p 내보내기
  6. 완성본 → 단톡방 공유 + Padlet QR 업로드
